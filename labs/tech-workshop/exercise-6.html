Test the Boomi Process

Click on the Test button available in the top right corner of the canvas.

Select the Atom where the Test is to be run. Select US East Test Atom Cloud atom for the test.

After selecting Atom, click on the Run Test button.

After clicking the Run Test button, one can see the process getting started, and once it reaches Stop Shape (End and Continue), that indicates the process ran successfully. Below screen will be presented.

Verify if the process ran successfully and the Boomi process was packaged and deployed correctly. Click on the Deploy menu on the top and select Packaged Components item.

The following screen will be displayed, showing the logs showing the process was packaged successfully.

Now Click on the Deploy menu on the top and select the Deployments item.

The following screen will be displayed, showing the logs showing the process was packaged successfully.

If you see the above result, then congratulations! Your Boomi process has been successfully packaged and deployed to your Test environment. To promote this package to Prod, you would be able to run the same process, but with different values. This is how Boomi can automate the promotion of deployable assets through and to production and fit nicely within any CI/CD tool. You can either put the Deploy API call in the CI/CD tool, call this Boomi Process or download the AtomSphere CLI that gives a command line interface to the Boom AtomSphere API.
