Lesson 1. A – Producer to Publishing Topic

Develop Pub/Sub Event-Driven Integration

While the Boomi runtime comes OOTB with an Atom Queue that implements the publish/subscribe message exchange pattern, the Atom Queue is meant for internal messaging within the Atom runtime. It is mostly used for guaranteed processing in the Atom and the ability to have asynchronous processing from within the same runtime. We recommend using the Boomi Solace Event Mesh for enterprise service buses and for supporting any external application to directly publish and subscribe to the Event Mesh. In these exercises, we will show you how to publish messages to the Event Mesh and how to subscribe to messages from the event mesh. Any protocol can be used to pub/sub to the event mesh, including JMS, REST, AMQP, MQTT, WebSocket, etc.

Click Services -> Integration and Navigate to your User Folder, click the black arrow down icon next to it, click New Folder and create a new folder called PubSub and click on Save.

Within your PubSub folder, create a New Component.

Choose Process, name the component Publish Message, and click the Create button.

In the Start Shape dialog, click the No Data radio button and OK. We are doing this so we can test our process to publish data to the Boomi Event Mesh.

Add a Message shape to the canvas. Drag the Message shape from Execute palette tab and drop it on the canvas. Click OK to dismiss the Message Shape dialog.

Enter solace in the Search shapes field at the top of the shape palette. Drag and drop the Solace PubSub+ Platform - Partner Connector on the canvas.

In the Connector Shape popup, select the Connection that is available in the #Shared Connections folder called (shared) Solace Connection.

In the same window, select the Action to Send.

In the same window, on the Operation field click on the button to create a new operation. Change the name to Publish to Topic and Save.

Adding the name to the Operation.

In the Solace Operation Window as seen above click on the Import button. Now, Select the Atom and Connection and click on Next.

From the Object Type drop-down, select OrderCreation Status and click on Next.

The operation will be loaded and the profile will be created by the wizard. Now click on Finish.

On the operation window now select the check box Return Application Error Responses and then click Save and Close button.

On the Connector Shape window all the configurations can be seen. Click on the OK button for the Connector Shape window.

Click the X in the Search Shapes field to remove solace. Drag and drop the set properties shape from Execute palette tab to the canvas.

In the Set Properties Shape popup, click on the icon to set the document properties for Solace Operation.

Click on the Connectors drop down, search for Solace, and select the Solace PubSub+ Platform - Partner Connector.

After selecting the Solace PubSub+ Platform - Partner Connector, a new field called Property can be seen. Select the Endpoint Type field value from the drop-down. Click the OK button.

After clicking OK

Click on the Solace Property value and Click on the button on the right side panel.

In the pop-up window select the Type Field as Static and the Static Value field as topic. Click the OK button.

The solace Property value for Endpoint Type is set.

Click on the icon under Properties to Set. Choose Connectors to Solace PubSub+ Platform - Partner Connector Property as Destination and click OK.

In the Properties to Set panel, click the Destination field, then the icon under Property Value and set the Static Value as CRMOppo/SAPOrder/Upsert/CRMApplication. Click the OK button.

Click on Logic Palette Tab and drag and drop Stop shape to canvas and click OK.

Copy the below XML message format, click on the Message shape and paste the content inside the Message box. Click on the OK button.

Sample message

<Response>

<SFDCOpptyId>Oppor123</SFDCOpptyId>

<SAPOrderNumber>SAP123</SAPOrderNumber>

<SFDCAcctId>Acct123</SFDCAcctId>

<SAPCustomerNumber>Cust123</SAPCustomerNumber>

<Message>Test Message</Message>

</Response>

Connect each step by clicking on the icon and dragging and dropping when hovering over the next shape.
