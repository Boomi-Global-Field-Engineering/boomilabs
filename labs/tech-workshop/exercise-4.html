Step 2 of 3

Build an ETL Process 2

Within your User - XX folder, create a new folder called 3.B - Build an ETL process 2 and click Save.

Within your 3.B - Build an ETL process 2 folder, create a New Component.

Choose Process, name the component ServiceNow Requests to Snowflake and click the Create button.

You will see a process is created with a Start shape. Click on Configure if the process start shape isn’t already open

Select the ServiceNow REST connector from the connector list.

Select QUERY in Action and the ServiceNow connection from the folder /Workshop/Immersive Hands On/#Shared Connections in Connection.

Click sign near in the Operation field to create a new operation.

Name the Operation as Get All Requests and click on Import.

Select the workshop_demo in Atom , ServiceNow in Connection, Actual Value in Display Value and sc_request in the Filter fields and then click Next.

Select Request (sc_request) in Object Type and click Next.

Click Finish. Notice the ML (Machine Learning) that the Boomi platform implements to make it easy and quick to build integrations. Since many of our users create a filter on the ServiceNow Request by number or sys_id, we offer this to the builder. ML/AI is pervasive throughout the platform.

Click Save and Close the Operation. Click OK to save the ServiceNow REST Connector Shape.

Search for and drag a Snowflake connector into the process canvas.

Select Bulk Load in Action, Choose…: Snowflake DB from the folder /Workshop/Immersive Hands On /#Shared Connections in Connection.

Click sign in Operation to create a new Snowflake operation.

Name the operation Load Requests from S3 and click on Import.

Select the Atom as workshop_demo, Connection as Snowflake DB and click on Next.

Select .DEMO.SERVICENOW_REQUEST (TABLE) and click on Next.

Click on Finish.

Fill in the Snowflake operation details for S3 Bucket Name use boomiworkshop, AWS Region of us-east-1, File Format Name of SERVICENOW_REQUESTS_CSV, File Format Type as CSV. Then click Save and Close and OK to save the connector.

In the Execute palette tab, drag a Map shape on the process Canvas.

Click on icon to create a new map.

Name the map as ServiceNow to Snowflake Map.

Click on choose on the Map Source.

Select JSON as Profile Type, ServiceNow REST Request (sc_request) FILTER_QUERY Response in Profile from /Workshop/Immersive Hands On/<your folder>/3.B - Build an ETL process 2 folder and click OK.

Click Expand All in the source profile to show all the data elements.

In the Map Destination panel, click Choose.

Select Flat File as Profile Type and SERVICENOW_REQUESTS in Profiles From /Workshop/Immersive Hands On/#Shared Assets folder and click OK.

Click Expand All in the destination profile to show all the data elements.

Click on Boomi Suggest. This is an Artificial Intelligence (AI) solution that allows you to automatically map data from any source to any target. Boomi saves every mapping that any customer has ever created in our Boomi Suggest repository. It has over 100 million maps of anonymized metadata of just the source attribute name and the target attribute name. If you don’t get a hit, manually create the mapping and Boomi will learn this map too. Since mapping is the most time consuming part of creating integrations, this will exponentially increase your productivity.

These are the mappings that Boomi found that applies to your data structures. Since Boomi Suggest is always learning, your hits may be slightly different. Click Next.

Boomi organizes the hits based on Low, Medium, and High matches. You can decide to accept or reject any of the mapping suggestions. Boomi customers, on average, accept over 90% of our suggestions. Change each From Path mapping in the High Confidence Matches this screen below

To this. Basically, uncheck the box in the first mapping and change each of the others to refer to the from attribute and click Next.

Clicking Next through any Medium, and Low Confident Matches.

When you see Suggestions Complete, click on Finish.

Notice that all of the mappings have been created automatically except for the number attribute. Boomi Suggest not only matches exact matching attributes, but also similar and any others that have been made on the platform.

To map the number field, lower the vertical scroll bar in the Map Source pane until you see number. Then hover over number in the Map Source panel, drag until you are hovering over the number field in the Map Target panel and drop to create the mapping.

The short_description and description fields in the ServiceNow Request object can contain double quotes. Since this is our token text qualifier, we need to replace them with single quotes. To do this, we need to use a Boomi String function. Click on the sign at the top of the middle Functions panel.

In the Category dropdown select String and in the Functions panel select String Replace and OK.

In the String to Search field enter “ and in the String to Replace enter ‘ and click OK.

In the Map, scroll down in the Map Source panel until you see the short_description attribute. Do the same for the Map Target panel. Your Map should look like this:

Hover over the short_description field in the Map Target panel until the cursor changes to four arrows. Left mouse click, drag and drop the existing map over the Original String input in the String Replace function. Now hover over the Result output of the String Replace function until the cursor changes to four arrows. Left mouse click, drag and drop the new map over the short_description field in the Map Target panel. The mapping should go through the function. When you get your Map to look like the following, click Save and Close.

We need to call the same function for the description field too. The easiest way to do this is to click on the Copy icon in the short_description String Replace function and click Paste at the bottom of the Functions panel. You will see another instance of the String Replace function added under the other one.

Scroll down in the Map Source panel until you see the description attribute. Do the same for the Map Target panel. Your Map should look like this:

Just like you did for the short_description field, hover over the description field in the Map Target panel until the cursor changes to four arrows. Left mouse click, drag and drop the existing map over the Original String input in the new String Replace function you just created on the bottom of the Functions panel. Now hover over the Result output of the new String Replace function until the cursor changes to four arrows. Left mouse click, drag and drop the new map over the description field in the Map Target panel. The mapping should go through the function. When you get your Map to look like the following, click Save and Close.

Drag and drop a Data Process shape to the canvas. In the popup, click the sign under Processing Steps, in the Processing Step drop down, select Combine Documents, in Profile Type, select Flat File, in Header Option click the Retain first line as Column Headers radio button, and click OK.

Drag drop a Stop shape to the canvas and click OK.

Arrange and Connect all the shapes. When your canvas looks like this, click Save.

Now lets deploy this process and run it. Click the Save button in the process and click on Create Packaged Component.

Click on Next:Add Details, then Create Packaged Component(1), then Deploy, select Private Cloud for Deployment Environment and Next: Select Version.

Click Next: Review, then Deploy, then Close.

Before you test your process, make sure to ask the instructor to clear out the SERVICENOW_REQUEST table in Snowflake so you will know exactly how many ServiceNow Requests get inserted.

Click Manage -> Process Reporting, then Execute Process. In the Execute Process dialog select workshop_demo for Select and Atom, navigate to and select ServiceNow Requests to Snowflake in your folder: /Workshop/Immersive Hands On/<your folder/3.B - Build an ETL process 2 for Process then Execute.

You can click the refresh button at the top of the Process Reporting page to see that the process is running. Feel free to click on the Time link and drill in to see the actual data passing through the process. You can ask the instructor if the ServiceNow Requests are loaded into Snowflake. Congratulations on completing this ETL exercise.

Build an ETL Process 3

Within your User - XX folder, create a new folder called 3.C - Build an ETL process 3 and click Save.

Within your 3.C - Build an ETL process 3 folder, create a New Component.

Choose Process, name the component Boomi aXis BW Extractor to Snowflake and click the Create button.

In the Start Shape dialog, select Connector as: Boomi aXis for SAP, Action: BW_GET and click on Choose… to select the Connection SAP S4H from /Workshop/Immersive Hands On/#Shared Connections directory.

Click the icon on the Operation tab, give Operation name as Get SAP BW Extractor Data. Click on Import, then select Atom : workshop_demo and Connection : SAP S4H from directory: /Workshop/Immersive Hands On/#Shared Connections, Filter : 0BPARTNER_ATTR and Next

If you see 0BPARTNER_ATTR as the Object Type click on Next, then Finish.

Your connector should look like this. If so, click OK.

Click on the Parameters (0 of 1 set) link on the canvas, and then the icon, select ID and OK as Input and enter Static Value as 0EEF203C9D411EDCB8F0A7A3CF61CF41. Make sure you don’t have any leading or trailing spaces. This is the SAP BW Extractor export ID. Click on OK.

Click on OK to save the Start Shape.

Drag a Map shape to the canvas, Choose… Map : SAP BP Extract to Snowflake Map from /Workshop/Immersive Hands On/#Shared Assets folder and then click OK.

Connect the Start Shape and the Map.

Search for Snowflake on Search shapes and drag the Snowflake connector to your canvas

Select Action : CREATE, and Connection : Snowflake DB from /Workshop/Immersive Hands On/#Shared Connections.

Click icon in the Operation field, give Operation name : Load SAP BP BW Extractor and click Import.

Select Atom : workshop_demo and Connection : Snowflake DB from

/Workshop/Immersive Hands On/#Shared Connections and Next.

Select Object Type : .DEMO.SAP_BUSINESS_PARTNER (TABLE) and click Next then Finish.

Update the Batch Size to 500 and click on Save and Close, then OK to save the connector.

Drag a Stop shape from Search shapes and connect the shapes together until it looks like the following.

Click on Save and Create Packaged Component.

Click on Next: Add Details.

Give Version for All : 1.0 and Package Notes for All : Initial Deployment and then click on Create Packaged Component(1).

Click on Deploy.

Select Private Cloud as the Deployment Environment and click on Next: Select Versions, then Next: Review, Deploy and Close.

Your process is now deployed and ready to execute. To do this, click on Manage -> Process Reporting.

You might want to check with your instructor to clear the SAP_BUSINESS_PARTNER table in Snowflake to make sure you actually sent 261 rows. Click Execute Process, and set Select an Atom : workshop_demo, Process : Boomi axis BW Extractor to Snowflake process you just created in the folder: /Workshop/Immersive Hands On/<your folder>/3.C - Build an ETL process 3
