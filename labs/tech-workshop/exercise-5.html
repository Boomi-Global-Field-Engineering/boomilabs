Step 1 of 2

Integration / write data back to SAP ECC

Create a Business Partner

Within your User - XX folder, create a new folder called 4.A - Build an integration with SAP ECC and click Save.

Within your 4.A - Build an integration with SAP ECC folder, create a New Component.

Name the component Create BP by IDoc and click the Create button.

On the Start Shape, select Type : No Data and click OK.

Drag a Message shape from the Execute panel of the shapes palette on the canvas. Copy and paste the data structure below into the Message section. Replace <your first name> with your first name and <your last name> with your last name or a fictitious one. Click OK.

FirstName,LastName

<your first name>,<your last name>

Drag and drop a Map shape onto the canvas. Click on the icon, navigate to /Workshop/Immersive Hands On/#Shared Assets and select Full Name FF to Create BP IDoc, and click OK.

Search axis on Search shapes and drag the Boomi aXis for SAP connector shape to your Canvas

Configure Connector shape with below details

Action : IDOC_SEND

Connection: Select SAP ECC from directory:- /Workshop/Immersive Hands On/#Shared Connections

Click icon in the Operation field, rename the Operation to SAP BP Create IDoc and click on Import.

Select the workshop_demo in Atom; SAP ECC in Connection and

BUPAFS_FS_CREATE_FRM_DATA201 in Filter. Click Next.

Select the Object BUPAFS_FS_CREATE_FRM_DATA201 and click Next, then Finish.

You will see the Request profile being created by the wizard once the import is complete. Click Save and Close then OK.

Drag a Stop shape on the process Canvas. Click OK. Connect all the shapes and rearrange them like the following.

Now test the process by clicking on Test. Use the Atom workshop_demo and click Run Test.

If the process executes successfully, click on the Stop shape, click on Shape Source Data, click on the document icon and note the IDoc Number in the DOCNUM XML element. Give this number to your instructor to execute the IDoc so the BP gets created. You will need the BP Number and the BP GUID to run the next exercise.

Step 2 of 2

Integrate / Write Data Back to SAP S4/HANA

Create Sales Order

Within your User - XX folder, create another folder called 5.A - Integrate / write data back to SAP S4/HANA, and create a New Component.

Name the component Create SO by FM and click the Create button.

On the Start Shape, select Type : No Data and click OK.

Select Salesforce connector and drag it to the canvas.

Select Action : Get and Connection : SE Shared SF from /Workshop/Immersive Hands On/#Shared Connections

Click on icon in Operation and change name to Query Opportunity and click on Import.

Choose Connection : SE Shared SF from /Workshop/Immersive Hands On/#Shared Connections by clicking on the magnifying glass and click on Next.

Select Object Type : Opportunity and Action : Query from respective dropdown menus and click on Next.

Expand Child Objects and check the box next to OpportunityLineItems. Expand OpportunityLineItems and check the box next to PricebookEntry. Scroll down and expand Parent Objects and also select Account. Boomi’s Salesforce connector can get data from all of these objects with just one call to the API. Click on Next then Finish.

Now click on the Filters tab at the bottom of the Salesforce Operation and click on the black arrow icon to the left of Filter and select Add Logical Sub-Group.

Now click on Add Expression, click on Expression, type Filter Name as ID= , select field Id from the profile drop down, then OK, select Operator as Equal To and click Save and Close.

Click on Parameters and click on import all 1? link.

Double click the row that was added to open the Parameter Value dialog, set Static Value : 0065G00000pugzKQAQ. This is the Salesforce Opportunity ID of the object we will be sending to SAP. Click on OK, then OK to save the connector.

Connect start shape with Salesforce connector shape.

Search for Set Properties shape and drag one to the canvas.

click on icon above the Properties to Set panel and select Property Type : Dynamic Process Property and Property Name : SAP_CustId_Trim click on OK.

Click on the Dynamic Process Property - SAP_CustId_Trim in the Properties to Set panel, click on the icon over the Property Value panel, select Type : Profile Element, Profile Type : XML, click Choose… in the Profile field, navigate to and select SF_Opportunity_QUERY_Response from /Workshop/Immersive Hands On/<your folder>/5.A - Integrate / write data back to SAP S4/HANA folder, and select Element : external_ID__c (Opportunity/Account/external_ID__c) at the very bottom then OK.

Repeat steps 16 - 17 to add another property called DPP_OPP_ID and Property Value will be Id (Opportunity/Id).

Click on OK, and connect the Salesforce connector to the Set Properties shape.

Drag a Map shape from Search shapes and choose SF Opp to SAP SO Map from /Workshop/Immersive Hands On/#Shared Assets, click on OK.

Connect the Set Properties shape to the Map shape.

Search axis in Search shapes and drag the Boomi aXis for SAP connector shape to your canvas.

Configure Connector shape with details:

Action : FUNCTION

Connection : Select SAP S4H from folder:- /Workshop/Immersive Hands On/#Shared Connections

Click icon in the Operation field. Change the operation name to salesorder_create and click on Import.

Select the workshop_demo in Atom; SAP S4H in Connection and

BAPI_SALESORDER_CREATEFROMDAT2 in Filter. Click Next.

Select the Object Type : BAPI_SALESORDER_CREATEFROMDAT2 and click Next then Finish.

Now the Request and Response Profiles can be viewed on the Operation tab. Click on Save and Close.

Click on OK and connect the Map shape to the Boomi aXis for SAP connection. Drag a Stop shape to the canvas, connect it to the Boomi aXis for SAP and click on Save. You process should look like this.

Now click on Test and select the workshop_demo Atom and click on Run Test.

Once the process is executed ( green color on each shape), click on the Stop shape and click on the Shape Source Data to view the results.

Make a note of the E_SALESDOCUMENT value, as you will need this value in the other exercises below. If you want to see the SAP Sales Order in the SAP GUI, ask your instructor to show you.
