Boomi Technical Workshop

Comprehensive technical workshop covering the full Boomi platform — provisioning, Pub/Sub event streams, REST APIs, ETL processes, SAP ECC and S/4HANA integration, CI/CD pipelines, data cataloging, API management, and platform monitoring.

~5 hours Advanced 8 Exercises

Exercises

  • 1

    Setup & Provisioning

    Log in to AtomSphere, set up your work folder, and walk through user provisioning patterns using Master Data Hub.

    ~30 min 2 steps
  • 2

    Pub/Sub Topics

    Build a producer process that publishes to a Boomi Event Stream topic, then a consumer that subscribes and reads from it.

    ~30 min 2 steps
  • 3

    API Building

    Build a simple REST API in Boomi, then expand to a complex API with multiple operations and error handling.

    ~45 min 2 steps
  • 4

    ETL Processes

    Build three progressive ETL processes — extract, transform, and load data through the Boomi process canvas.

    ~50 min 3 steps
  • 5

    SAP Integration

    Write business object data back to SAP — first to SAP ECC (Business Partner), then to SAP S/4HANA (Sales Order) — covering Create, Update, and Delete operations.

    ~45 min 2 steps
  • 6

    CI/CD Pipeline

    Leverage a CI/CD pipeline to build and deploy your Boomi processes automatically — covering source control integration, environment promotion, and automated testing.

    ~30 min 1 steps
  • 7

    Data Sets & Catalog

    Load a large data set, catalog it for reuse across the organization, and subscribe to a published catalog data set as a consumer.

    ~25 min 3 steps
  • 8

    API Mgmt & Operations

    Apply API Management to your APIs, configure failover/retry behavior for resilience, then monitor and dashboard the running platform.

    ~40 min 3 steps

Prerequisites

  • Access to Boomi AtomSphere (platform.boomi.com) — credentials provided by your trainer
  • Access to Boomi services: Master Data Hub, Event Streams, API Management, Data Catalog
  • SAP ECC and SAP S/4HANA test instances (Exercise 5)
  • Access to a CI/CD pipeline (Exercise 6) and a Snowflake test database (Exercises 7, 8)
  • Solid prior experience with the Boomi AtomSphere canvas — this workshop covers a wide range of advanced topics
