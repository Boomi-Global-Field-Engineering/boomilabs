Exercises

1

Connect to SAP and Create a Table Service

Log in to the Boomi for SAP UI, join the VBAK and VBAP tables on a canvas, and publish a Table Service that exposes SAP sales order data as a clean OData feed.

Boomi for SAP Table Service VBAK / VBAP
~25 min5 steps
2

Extract SAP Data into Snowflake

Set up your Snowflake target, configure the SAP Table Service as a source in Boomi Data Integration, and run an initial full load of sales order data into the Snowflake RAW schema.

Boomi Data Integration Snowflake Source-to-Target Flow
~30 min5 steps
3

Transform SAP Data into a Data Warehouse

Add a SQL Transformation step to your BDI pipeline that builds a FACT_SALES table and a DIM_CUSTOMER dimension in Snowflake, then use Snowflake Cortex to explore the results.

SQL Transformation Fact / Dim Tables Snowflake Cortex
~20 min4 steps

Prerequisites

  • Boomi for SAP UI access — Log in at boomiforsap.demo.boomi.com. Credentials provided by your trainer.
  • Boomi Data Integration account — Log in at console.rivery.io. Credentials provided by your trainer.
  • Snowflake trial account — Open a free 30-day trial at signup.snowflake.com. New to Snowflake? Follow the step-by-step signup guide.
  • No prior SAP or Snowflake experience required — all steps are explained from scratch.
