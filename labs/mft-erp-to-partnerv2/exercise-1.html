Exercise 1 — Overview

Configure the MFT Flow

Set up your Automated File Transfer (AFT) portal with partner organizations, endpoints, and a distribution flow.

Scenario
CRM → Partner Fan-Out
Duration
~30 minutes
Steps
3 steps
Platform
AFT Portal

The Scenario

You are representing X Battery, a major supplier in the automotive industry. Your CRM system generates invoices, purchase orders, and shipping notices that need to be automatically distributed to multiple automotive partners: BMW, Mazda, and Volkswagen.

The challenge: files are generated from an internal system (simulated by a Boomi process) that appends the partner name to each filename. These files need to be routed automatically so each partner receives only their specific files — with full multi-tenant isolation.

Lab Objective: The "Fan-Out" Pattern

You will configure a distribution pattern where a single Boomi integration pushes files into the MFT platform, which then routes them to the correct partner based on file naming rules:

  • Integration ➔ MFT ➔ Target: BMW
  • Integration ➔ MFT ➔ Target: Mazda
  • Integration ➔ MFT ➔ Target: Volkswagen

Technical Architecture

  • Source: A Boomi integration process that creates source data and passes it to the Boomi MFT connector
  • Routing Logic: MFT routes files to each partner target endpoint based on filename regex filters
  • Security: Multi-tenant isolation — partners cannot "see" into other directories
In Exercise 1 you will work entirely in the AFT Portal. In Exercise 2 you will switch to the Boomi Integration platform to build the process that feeds into it.

Step 1 of 3

Create Organizations & Endpoints

In the AFT portal, create organizations for each automotive partner and add the appropriate endpoints to each.

Log into the AFT portal at https://staging.thruinc.com/ before starting this step.
  1. 1

    From the overview page, navigate to Organizations.

  2. 2

    Click Add Organization and create three organizations named: BMW, Mazda, and VW.

  3. 3

    Within each of these organizations, select Endpoints and add an endpoint of type MFT SFTP. Name each endpoint SFTP Server.

  4. 4

    Add an additional organization called Integration.

  5. 5

    Within the Integration organization, add an Endpoint. Choose the type Boomi MFT Connector and name it Boomi Integration.

  6. 6

    Click Save on the Boomi Integration endpoint. The page now shows three values that the Boomi connector will use to log in to MFT:

    • OAuth Access Token URL, for example https://staging-api.thruinc.com/oauth/token
    • Client ID, a long value starting with bc-
    • Client secret, shown in the green box that says "Copy your client secret now — it won't be shown again."

    Click the copy button next to the client secret and paste it into the Description box at the bottom of the page. Then click Save again.

    Copy the client secret before you leave this page. It is shown only once. If you lose it, click Generate client secret to create a new one, then copy that one.
You should now have 4 organizations (BMW, Mazda, VW, Integration) each with an endpoint configured. These are all the participants that will take part in the MFT flow.

You should also have saved the OAuth Access Token URL, the Client ID and the client secret from the Boomi Integration endpoint. You will need all three in Exercise 2.
Step 2 of 3

Create the Distribution Flow

Create a new MFT Flow that defines how files will be distributed from the Boomi integration to the three automotive partners.

  1. 1

    From the AFT portal, select Flow from the sidebar and click Add Flow.

  2. 2

    Name the Flow:

    Boomi Integration (CRM/Source → AFT → Multiple Partner Targets)
  3. 3

    Click Save. Once saved, you will land in Flow Studio.

Flow Studio is where you will visually wire together the source (Boomi Integration) and targets (BMW, Mazda, VW). You'll configure this in the next step.
Step 3 of 3

Add Subscribers & Flow Endpoints

Subscribe all organizations to the flow, then wire up both the target (partner) and source (integration) endpoints in Flow Studio.

Add Subscribers

  1. 1

    In Flow Studio, click on Subscribers, then click Add Subscribers.

  2. 2

    Select all the organizations (BMW, Mazda, VW, Integration) and click Subscribe Selected.

Add Target Flow Endpoints

  1. 3

    Back in Flow Studio, click ADD FLOW ENDPOINT on the Target Side. Add each manufacturer in turn, selecting the SFTP Server Endpoint for each. Repeat for BMW, Mazda, and VW.

  2. 4

    Flow Studio should now look like this on the target side — three partner endpoints visible.

Add Source Flow Endpoint

  1. 5

    Click ADD FLOW ENDPOINT on the Source Side. From the available sources, choose Integration.

  2. 6

    Select the available endpoint (Boomi Integration).

  3. 7

    Write down your Flow Endpoint ID. The Sources table now shows one row. In the Flow Endpoint column, the name starts with a number followed by a colon, for example 26554: Boomi Integration.

    The number before the colon is your Flow Endpoint ID. In this example it is 26554. Yours will be different. Write it down, because you will type it into the Boomi connector in Exercise 2.

    Use the number from the Flow Endpoint column only. Do not use:
    • the endpoint Code (letters and numbers, for example ENDCB7P) shown on the endpoint page in Step 1
    • the flow code (starts with FL)
    The connector only accepts the plain number, for example 26554.
Before moving on — click the blue pulsing View and Push Changes button, then confirm, to make the flow live. This step is easy to miss. Until you push, the Boomi connector cannot send files into the flow, and your test in Exercise 2 will fail with an authorization error such as:

Embedded message: Server returned HTTP response code: 401
