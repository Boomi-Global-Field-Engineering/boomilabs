Boomi MFT

Many to One
(Partners → Headquarters)

Automate the secure delivery of files from multiple partner organizations into a single headquarters server using Boomi's Managed File Transfer platform. Implement the many-to-one pattern — partners upload files via SFTP and MFT routes each file to the correct target folder at headquarters, with full partner isolation and optional PGP encryption.

~90 minutes 1 exercise · 6 steps + bonus Basic
This lab was originally built for a live workshop. If you're working through this outside of a workshop session, you'll need to set up your own accounts before starting. You can get access by going to Boomi MFT trial. Workshop participants will have accounts pre-provisioned — check your inbox for a registration email.
Start Lab

Exercises

1

Configure the MFT Flow

Create four organizations (Headquarters and three Partners) in the AFT portal, add SFTP endpoints to each, build a Many-to-One flow in Flow Studio, subscribe all organizations, configure source endpoints per partner, set up target path mapping at headquarters, then test the end-to-end transfer using FileZilla or the built-in upload widget. Includes an optional bonus step for adding PGP encryption.

AFT Portal Organizations Flow Studio SFTP Path Mapping
~90 min 6 steps + bonus

Prerequisites

  • AFT portal account — your account will be created in advance and you will receive an email to complete registration. Log in at staging.thruinc.com
  • Basic familiarity with SFTP concepts (host, username, password, directory navigation)
  • Optional but recommended: FileZilla (or another SFTP client such as WinSCP) installed for the hands-on file transfer steps
