Overview

Exercise 2 — Table Services: SAP Sales Orders to a Database

5 min

In this exercise you will use the Boomi for SAP UI to create a custom Table Service that joins two SAP tables (VBAK and VBAP), then build a Boomi integration process that queries that service and writes the results into a relational database.

What you'll learn
  • How to build a Table Service in the Boomi for SAP UI by joining SAP tables
  • How to use the Boomi for SAP connector with the QUERY action
  • How to configure a Database connector with a Dynamic Insert profile
  • How to map SAP fields to database columns in a Boomi map

Two-part exercise

  1. Section 1 — Create a Table Service in the Boomi for SAP UI joining VBAK + VBAP
  2. Section 2 — Build an AtomSphere process to query the service and load a database
Replace XXReplace XX throughout this exercise with your assigned initials or user number.

Section 1 · Step 2 of 3

Build the Table Service — Join VBAK & VBAP

10 min
  1. 3

    In the search box, type VBAK to find the Sales Document Header table. Drag it onto the canvas.

  2. 4

    Search for VBAP (Sales Document Item Data) and drag it onto the canvas.

  3. 5

    Create a join by selecting the Sales Document field (VBELN) from the VBAK table and dragging it to the VBELN field on the VBAP table. This creates an inner join on the document number.

  4. 6

    Click the filter fields icon on each table and deselect all fields by clicking the top checkbox.

  5. 7

    Re-select only the following fields:

    VBAK (Sales Document Header):

    VBELN, ERDAT, AUDAT, VBTYP, NETWR, WAERK,
VKORG, VTWEG, SPART, VKGRP, VKBUR, GSBER, KUNNR

    VBAP (Sales Document Item Data):

    VBELN, POSNR, MATNR, CHARG, MATKL, ARKTX, PSTYV, KWMENG, KMEIN

Section 2 · Step 2 of 4

Configure the Start Shape (Boomi for SAP — QUERY)

10 min
  1. 12

    Click the Configure link on the Start shape. In the connector configuration, select SAP S4 Connection from the drop-down.

  2. 13

    Click + to create a new operation. Ensure the Action is set to QUERY.

  3. 14

    On the Connector Operation screen, enter an operation name (e.g., Query Sales Orders USERXX) and click Import.

  4. 15

    In the Import Wizard, select your Atom connection and filter by your Table Service name (SALES_ORDERS_XX). Click Next twice, then Finish.

  5. 16

    The profile is now imported. Change the Max Returned Rows value to 100 and click Save and Close.

  6. 17

    Click OK to return to the canvas.

Section 2 · Step 3 of 4

Configure the Database Destination Shape

12 min
  1. 18

    Click Configure on the Database shape.

  2. 19

    In the Connector Shape, select the existing database connection.

  3. 20

    Set Action to Send and click + to create a new operation. Click OK.

  4. 21

    In the Database Operation screen, enter an operation name and click + to create a new Database Profile.

  5. 22

    Give the profile a name. Click Statement, choose type Dynamic Insert, then click Import.

  6. 23

    In the Database Import Wizard, select the appropriate options and click Next.

  7. 24

    Select the Sales Orders SAP table and click Next.

  8. 25

    Select all fields, click Next, then Finish.

  9. 26

    Name the Database Profile SO DB Profile USERXX. Click Save and Close on the profile, then Save and Close again on the operation, and finally OK to return to the canvas.
