Overview

Quote Parts Lab

Build an AI-powered Quote Parts Agent that processes Bills of Materials, connects to supplier systems for live pricing, and generates accurate quotes in minutes.

Lab Type
Instructor-Led
Category
Financial Operations
Steps
14 steps
Source
labs.boomi.com

Precision Source Manufacturing's manual quoting process takes days or weeks. This lab builds a Quote Parts Agent that processes BOMs, matches parts, and generates CSV quotes automatically.

Canonical Source

This lab guide was authored for the Boomi Labs site. The canonical version with the latest updates can be found at https://labs.boomi.com/labs/financial-operations/quote-parts/intro.

Step 1 of 14

Activity 1: API Tools for an AI Agent

Create two API tools: the Parts Query API Tool and the PIM Classification API Tool.

Step 2 of 14

Access Agentstudio

  • Select the AI button in the top right of Boomi Platform.
  • Select Get Started, accept Terms and Conditions.
Step 3 of 14

Build the Parts Query API Tool

  • Select Agent Designer → Tools tab → Create New Tool → API Tool → Add Tool.
  • Tool Name: [builderInitials] Parts API | Description: Retrieve cleansed and validated parts information from the ERP.
  • Add Input Parameter: category (String, Required True)
  • Add Input Parameter: class (String, Required True)
  • Configuration: Base URL https://c04-usa-east.integrate.boomi.com | GET /ws/rest/tools/parts | Query: category={{category}}, class={{class}} | Basic Auth.
  • Deploy Tool → Deploy.
Step 4 of 14

Build the PIM Classification API Tool

  • Create New Tool → API Tool → Add Tool.
  • Tool Name: [builderInitials] PIM Classification Data | Description: Retrieve parts metadata from the PIM system
  • Configuration: GET /ws/rest/tools/pimClassifications | Basic Auth.
  • Deploy Tool → Deploy.
Step 5 of 14

Activity 2: Building an AI Agent

Create the Quote Parts Agent using Build with AI, attach tools to tasks, and configure guardrails.

Step 6 of 14

Set up Agent Profile

  • Select Agent Designer → Agents tab → Blank Template → Build with AI.
  • Enter Goal: The AI agent's primary goal is to accelerate the quote-to-cash cycle by automating the manual quoting process...
  • Edit Basic Information, set Agent Name: [builderInitials] Quote Parts
  • Review Voice settings (Professional recommended).
  • Review Conversation Starters.
Step 7 of 14

Set up Agent Tasks

  • Ensure 4 tasks exist: Process Bill of Materials, Product Catalog Matching, Supplier Data Retrieval, Quote Generation.
  • Attach [builderInitials] Parts API to Product Catalog Matching task.
  • Attach [builderInitials] PIM Classification Data to Supplier Data Retrieval task.
Step 8 of 14

Set up Guardrails

  • Review Supplier System Integrity guardrail.
Step 9 of 14

Test Agent with BOM

  • Submit a BOM XML in the Test Agent panel and verify the agent matches parts and generates a CSV quote.
  • Select Deploy Agent. Open Chat and select your agent from the top-left dropdown.
Step 10 of 14

Activity 3: Agent Step

Build an integration process to programmatically invoke the Quote Parts Agent using Boomi's integration tools.

Step 11 of 14

Return to Integration

  • Navigate to Integration under the menu next to the AI icon.
  • In your folder under Workshop Assets → Participants, create New Component → Process → Data Passthrough.
Step 12 of 14

Add Message Step

  • Click + and search for message. Add a Message step with the BOM XML as content.
Step 13 of 14

Add Agent Step

  • Click + and search for agent. Select your [builderInitials] Quote Parts agent.
  • Click Generate Configuration.
  • Authentication tab → Platform API Token: 63736a0d-dfa0-475c-a139-73ed8c364731
Step 14 of 14

Complete and Test

  • Add Stop step, rename process to Quote Parts Agent Step, Save.
  • Click Test, select Test runtime, OK.
  • Select Stop step → Step Source Data → paper icon to view JSON payload.
Congratulations! You completed all Quote Parts activities.
