MFT Runtime Workshop · Tech Lab Exercise

Install & test the MFT Runtime (Thru Node)

A hands-on, step-by-step lab for installing the Boomi MFT Runtime on a pre-provisioned workshop VM, and running a real LAN-to-LAN file transfer end to end — no customer infrastructure required.

Audience: POC & workshop participants
Estimated time: ~40 min core lab · +15 min bonus exercise

Why this lab exists

POC engagements were losing days waiting on customers to provision a VM just to test the MFT Runtime. This lab pairs a hands-on exercise with an on-demand, pre-provisioned VM so you can go from zero to a working, tested runtime in under an hour — no IT ticket required.

You'll create an Organization and a Runtime, install it, configure a File Share Endpoint, build a LAN-to-LAN flow, and prove a file moves end to end — the exact pattern used in real customer POCs.

What you'll need

  • Your workshop registration email (WorkSpaces + MFT credentials)
  • It's useful to have already preset your MFT password before the workshop starts
  • About 30–45 minutes, uninterrupted
  • No admin rights required — the lab is designed around that constraint

Not at a workshop? You'll need a machine with Windows installed, plus your own Boomi MFT account — sign up for a Boomi MFT trial. Workshop participants get an account pre-provisioned automatically — check your inbox for a registration email.

Cloud ↔ Runtime (inbound/outbound)

The most common pattern. A file is staged in the MFT cloud and the runtime pulls it down, or the runtime picks up a local file and pushes it to the cloud for a partner to collect. The cloud is the intermediary.

LAN to LAN

The runtime moves a file from one local location to another entirely within your network, without the file ever touching the MFT cloud. Useful for sensitive files or when egress cost is a concern. This is the pattern you just built.

Direct delivery / fan-out

The runtime picks up one source file and delivers it simultaneously to multiple external destinations, each with its own independent processing — common in manufacturing, retail, and supply chain scenarios.
