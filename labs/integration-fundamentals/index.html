Boomi Integration Fundamentals — Hands-on Lab

Build your first Boomi integration end-to-end — query Salesforce for prospect accounts, check for duplicates against a database, and write new records back. A foundational walkthrough of connectors, decision logic, mapping, and notifications.

~90 min Foundational 3 Exercises

Exercises

  • 1

    Set Up & Connect to Salesforce

    Log in to AtomSphere, create your first integration process, and test connectivity to Salesforce.

    ~25 min 3 steps
  • 2

    Build the Integration Logic

    Add the database connector, route records with a Decision step, configure True/False paths, and map the data into the target schema.

    ~40 min 5 steps
  • 3

    Complete & Test the Process

    Insert records into the database, configure a Message step, send a notification email, and run the process end-to-end.

    ~25 min 4 steps

Prerequisites

  • Access to Boomi AtomSphere (platform.boomi.com) — credentials provided by your trainer
  • A pre-configured Salesforce connection and database connection profile — provided by your trainer in the SHARED folder
  • An SMTP/mail account for the notification step in Exercise 3
  • An assigned User-XX folder in your Boomi training account
