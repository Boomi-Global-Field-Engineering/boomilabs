Overview

Intelligent Churn Detection Lab

Build an Intelligent Churn Detection Agent for Retentix that consolidates customer health data, detects risk signals, and triggers proactive retention workflows.

Lab Type
Instructor-Led
Category
Customer Operations
Steps
17 steps
Source
labs.boomi.com

Retentix struggles with siloed customer data across product usage, support, and CRM systems. This lab builds an agent that consolidates data, assesses churn probability, classifies risk segments, and triggers escalation workflows.

Canonical Source

This lab guide was authored for the Boomi Labs site. The canonical version with the latest updates can be found at https://labs.boomi.com/labs/customer-operations/intelligent-churn-detection/intro.

Step 1 of 17

Prerequisites

  • Create Agent Testing environment and attach a Basic Runtime (see other labs for detailed steps).
Step 2 of 17

Create Notification and Escalations Integration

  • Navigate to Integration → your folder → New Component → Process → No Data.
  • Process: Start → Notify (I am simulating an API call to the notification and event applications.) → Stop
  • Name: [builderInitials] Notification and Escalations Integration. Package, Deploy to Agent Testing.
Step 3 of 17

Activity 1: API Tools for an AI Agent

Build three tools: Customer 360 API Tool, Customer Retention Metadata API Tool, and Notification and Escalations Integration Tool.

Step 4 of 17

Build Customer 360 API Tool

  • Agentstudio → Agent Garden → Tools → Create New Tool → API Tool → Add Tool.
  • Tool Name: [builderInitials] Customer 360 | Description: Retrieve cleansed and validated customer information from the Golden Record.
  • Add Input: contactId (String, Required False) | GET /ws/rest/tools/contact | Query: contactId={{contactId}} | Basic Auth.
  • Deploy → Deploy.
Step 5 of 17

Build Customer Retention Metadata API Tool

  • Tool Name: [builderInitials] Customer Retention Metadata | GET /ws/rest/tools/contactMetadata | Query: customerId={{customerId}}
Step 6 of 17

Build Notification and Escalations Integration Tool

  • Integration Tool → Name: [builderInitials] Notification and Escalation
  • Input: Name (String, Required). Environment: Agent Testing | Process: [builderInitials] Notification and Escalations Integration | DPP: Name={{Name}}
Step 7 of 17

Activity 2: Building an AI Agent

Create the Intelligent Churn Detection Agent using Build with AI and attach tools to tasks.

Step 8 of 17

Build Agent with AI

  • Agent Designer → Agents → + button → Build with AI.
  • Enter churn detection goal. Set Name: Intelligent Churn Agent [builderInitials].
Step 9 of 17

Attach Tools to Tasks

  • Ensure 5 tasks: Customer 360 Data Retrieval, Churn Risk Assessment, Risk Classification, Predictive Reporting, Notification and Escalation.
  • Task 1 (Data Retrieval): Attach [builderInitials] Customer 360.
  • Task 2 (Churn Risk Assessment): Attach [builderInitials] Customer Retention Metadata.
  • Task 5 (Notification): Attach [builderInitials] Notification and Escalation.
Step 10 of 17

Configure Guardrails

Step 11 of 17

Test and Deploy

  • Test: What are the current churn prediction insights for our customer base?
  • View trace steps to see tool invocations.
  • Test: Is Christopher Gonzales a churn risk?
  • Deploy Agent. Open Chat, select your agent.
Step 12 of 17

Activity 3: Agent Step

Create a Platform API Token and build an integration process to programmatically invoke the Churn Detection Agent.

Step 13 of 17

Create a Platform API Token

  • Settings → Platform API Tokens → Add New Token named 'Intelligent Churn Agent Token'.
Step 14 of 17

Build the Integration Process

  • Return to Integration → New Process in your folder → Data Passthrough.
Step 15 of 17

Add Message Step

  • Search for message step, enter: Is Christopher Gonzales a churn risk? Return as JSON with risk level.
Step 16 of 17

Configure Agent Step

  • Add Agent step → search for agent.
  • Select Intelligent Churn Agent [builderInitials].
  • Authentication tab → paste Platform API Token.
Step 17 of 17

Complete and Test

  • Add Stop step. Rename: Agentstudio Agent Step. Save.
  • Test → select Test runtime → OK.
  • Select Stop step → Step Source Data → paper icon → view JSON payload.
You built an Intelligent Churn Detection Agent that transforms retention from reactive to proactive!
