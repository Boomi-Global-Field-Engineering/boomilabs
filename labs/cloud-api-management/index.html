Cloud API Management — Hands-on Lab

Take a public API from specification to a governed, discoverable product. Import the Petstore OpenAPI spec into Cloud API Management, wire up Traffic Routing, design Packages and Plans for three departments, generate Package Keys, then discover and publish everything through API Control Plane and a branded Developer Portal.

~2 hours Foundational 5 Exercises

Exercises

  • 1

    Get Set Up

    Log in to your Boomi Platform training account, grant yourself the Cloud API Management and API Control Plane roles, and open both services.

    ~15 min3 steps
  • 2

    Navigate Cloud API Management

    Tour the Control Center — API Definitions, API Packages, Applications, Organizations, and Package Keys — and learn what each page is for before you build.

    ~20 min6 steps
  • 3

    Organizations & the API Definition

    Create the Organizations that govern access, import the Petstore OpenAPI spec as your first API Definition, and configure EndPoint Domains and Traffic Routing — the heart of Cloud API Management.

    ~30 min3 steps
  • 4

    Packages, Plans & Package Keys

    Design a Packages-and-Plans strategy for three departments, explore the generated Interactive Documentation, edit the API Specification, then create an Application and generate the Package Key that authorizes calls.

    ~35 min5 steps
  • 5

    API Control Plane & the Developer Portal

    Verify your Cloud API Management gateway is connected, discover your APIs and API Products, publish them to the Developer Portal, then customize the portal and call your API live from it.

    ~30 min4 steps

Prerequisites

  • A Boomi Platform training account (platform.boomi.com) — credentials provided by your trainer
  • Permission to edit your own user roles (Exercise 1 walks you through adding the Cloud API Management and API Control Plane roles)
  • No prior API Management experience required — the exercises build on each other from zero
Want the full course? These activities are a short version of a full Boomi World pre-conference training. The complete Cloud API Management course is available on the Boomi LMS at train.boomi.com.
