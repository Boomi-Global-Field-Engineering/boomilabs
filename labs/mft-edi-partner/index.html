Boomi MFT · EDI

Trading Partner SFTP
& EDI Processing

Combine Boomi MFT's File Sharing module with Boomi Integration's EDI Trading Partner module to provide trading partners with a secure, hosted SFTP server — with built-in compliance, auditability, and scale. Partners upload EDI files via SFTP or the web portal; Boomi handles validation, routing, acknowledgement, and downstream delivery automatically.

~90 minutes 2 exercises Basic
Start Lab

Exercises

1

Explore the File Sharing Portal

Log into the Boomi MFT File Sharing web portal, navigate the pre-built folder structure, and copy an EDI 850 purchase order file from the shared library into your personal Inbox — simulating a trading partner dropping off a file for processing.

File Sharing Portal SFTP EDI 850
~20 min 2 steps
2

Configure the EDI Integration Process

In Boomi Integration, copy the pre-built EDI Workshop process from the source library, configure the ABCD Trading Partner's SFTP communication settings to point to your File Sharing user, wire up the Simulated SAP, Rejected, and Error SFTP connections to your return folders, then run a live test to process the EDI file end-to-end and review the results in the activity log.

Boomi Integration Trading Partner SFTP Connector EDI 850 SAP ORDERS05
~70 min 5 steps

Prerequisites

  • File Sharing portal account — if attending a workshop, your account will be created in advance and you will receive an email to complete registration. Log in at sftp-trading-partner-demo.boomi.com. If completing this lab independently, you will need access to your own Boomi MFT File Sharing instance.
  • Boomi Integration account — if attending a workshop, your account will be created in advance and you will receive an email to complete registration. Log in at platform.boomi.com. If completing this lab independently, you will need an existing Boomi Integration account.
  • Basic familiarity with SFTP concepts and the Boomi Integration canvas
  • Optional: an SFTP client such as FileZilla or WinSCP if you prefer to interact with the File Sharing server directly over SFTP rather than through the web portal
