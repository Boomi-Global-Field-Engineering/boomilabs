Demo 05 — Overview

Manufacturer to Supplier Distribution

A manufacturer uploads into supplier-specific paths and Boomi MFT routes each file to the correct supplier automatically — with complete target isolation.

What This Demo Covers

A manufacturer uploads files into the MFT platform using either the browser-based upload widget or SFTP. Files are placed into supplier-specific paths — BMW, Mazda, or Volkswagen. Boomi MFT routes each file to the corresponding supplier's target endpoint automatically. Each supplier receives only their own files, with no visibility into the others.

Key Capabilities

  • Upload widget with 3 selectable source paths (BMW, Mazda, Volkswagen)
  • Optional FileZilla export for SFTP-native access — zero manual configuration for the partner
  • Source-to-target path mapping — each upload path routes to a dedicated supplier target
  • Per-supplier target isolation — full multi-tenancy across all three partners
  • Activity verification showing "Ready for Download" state per supplier

Architecture

Manufacturer (Upload widget or SFTP push) → Path Selection (BMW / Mazda / Volkswagen) → Boomi MFT Path Mapping → Suppliers (each receives only their own files)

The automotive supplier scenario — BMW, Mazda, Volkswagen — illustrates fan-out file distribution in a familiar, real-world context that applies across manufacturing, retail, and financial services.
Step 1 of 3

Open Demo 05

Review the flow structure and explore the optional FileZilla export path.

  1. 1

    Navigate to Flows → 05 Manufacturer to Supplier. Review the source (manufacturer) and targets (BMW, Mazda, VW). Note that each supplier is a separate organization with its own dedicated endpoint.

  2. 2

    (Optional) On the flows page, click Export to FileZilla. Import the XML into FileZilla to connect and push files via SFTP. FileZilla export generates a fully pre-configured site XML in one click — partners can connect immediately with no manual SFTP setup.

Step 2 of 3

Upload Widget & Test File

Use the upload widget to inject a file into a specific supplier path.

Wait for "Completed" before navigating away. Use a small file (under 1 MB) for the best results.
  1. 1

    In the Demo 05 sources list, click the Action icon → Upload Files. The widget shows 3 paths: BMW, Mazda, Volkswagen.

  2. 2

    Choose a specific supplier path — for example, BMW.

  3. 3

    Select a small file and upload. Wait for the "Completed" status before navigating away.

Step 3 of 3

Path Mapping & Activity

Review the routing rules, then confirm your file landed in the correct supplier folder.

  1. 1

    On the target side of Demo 05, open the Mapping tab. Review how BMW, Mazda, and VW source paths each map to a dedicated supplier target path — automatic routing with no manual intervention.

  2. 2

    Navigate to Activity → filter by "Manufacturing to Supplier" → Apply.

  3. 3

    Find your uploaded file in "Ready for Download" state. Confirm it landed in the correct supplier folder (BMW target, not Mazda or VW).

Demo 05 complete. Upload widget path selection → automatic routing via path mapping → Activity verification — a complete end-to-end story for supplier file distribution.
