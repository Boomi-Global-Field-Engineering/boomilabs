Guided Demos

01
Multi-Bank Statement Aggregation
Multiple partner banks push statement files to a Boomi-hosted SFTP server. PGP encryption end-to-end, antivirus scanning on arrival, and root-level partner isolation.

02
Automated Clinical Data Transfers
An external upload portal feeds files into Boomi MFT, which triggers a Boomi Integration process. The file is renamed with a processing outcome and returned to the Activity feed.
Upload PortalIntegrationRound-Trip
03
Scheduled File Transfer
Time-triggered flow that runs continuously — files transfer on a defined schedule with no manual intervention. Ideal for batch, ERP export, and end-of-day reporting use cases.
ScheduledBatchAlways-On
04
SFTP Server Pull
Boomi MFT actively polls and pulls from an external SFTP server — demonstrating enterprise-initiated transfers without requiring the partner to change their processes.
SFTP PullOutboundEnterprise-Initiated
05
Manufacturer to Supplier Distribution
A manufacturer uploads via browser or SFTP into BMW, Mazda, or VW paths. Boomi MFT routes each file to the correct supplier automatically — with full target isolation.
Fan-OutPath RoutingUpload Widget
06
On-Premises Runtime & File Share
A Boomi runtime agent monitors a local file share and bridges it to cloud MFT — no firewall changes required. Includes filename filtering, rename steps, and the full monitoring story.

Before You Begin

  • Access to the Boomi MFT demo environment — log in via the tile in your Okta portal
  • A small test file under 1 MB (CSV preferred) for the live upload steps in Demos 01 and 05
  • Optional: FileZilla installed if you want to follow the SFTP-native path in Demo 05
  • For Demo 02: access to the Healthcare Upload Portal — provided separately as part of your environment setup
