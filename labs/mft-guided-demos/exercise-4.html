Demos 03 & 04 — Overview

Scheduled & SFTP Pull Transfers

Two always-active flows — no manual upload required. Both generate continuous activity visible in the Activity feed at any time.

Demo 03: Scheduled File Transfer

A schedule-triggered flow moves files on a defined interval — continuously, without any manual intervention. This is ideal for batch use cases: ERP exports, end-of-day reports, and regulatory submissions. Define the schedule once and Boomi handles the rest.

Demo 04: SFTP Server Pull

Rather than waiting for a partner to push files, Demo 04 shows Boomi MFT actively polling and pulling from an external SFTP server. This gives you control over transfer timing without requiring the partner to change their existing processes or infrastructure.

Both flows run continuously. Filter by either in the Activity feed to see a live stream of completed transfers — no file upload required.
Step 1 of 4

Demo 03: Schedule Configuration

See how time-based triggers automate file transfers without any partner coordination.

  1. 1

    Navigate to Flows → Demo 03. Click the flow endpoint to open its configuration.

  2. 2

    Open the Schedule tab. Review the time-based trigger configuration — interval, start time, and recurrence. Schedule-triggered flows are ideal for batch scenarios where the business defines when files should transfer and Boomi enforces it automatically.

  3. 3

    Review the Source Path configuration — this is where the endpoint monitors for files on each scheduled interval.

Step 2 of 4

Demo 03: Activity Review

A continuous stream of completed scheduled transfers — every interval logged.

  1. 1

    Navigate to Activity → filter by Demo 03 → Apply.

  2. 2

    A continuous stream of Completed transfers is visible — every scheduled interval is logged. Click any entry to expand the file lifecycle.

Step 3 of 4

Demo 04: Pull Configuration

Enterprise-initiated transfers — Boomi pulls from a partner SFTP rather than waiting for a push.

  1. 1

    Find Demo 04 — SFTP Server Pull in the Flows list. Open the flow endpoint for configuration.

  2. 2

    Review the Source configuration — the source is an external SFTP endpoint. Boomi MFT polls and pulls from the remote server on a schedule. Unlike traditional push architectures, this gives the enterprise control over transfer timing without requiring the partner to change their processes.

  3. 3

    Review the Delivery Target — files are collected from the source and delivered to the configured target automatically.

Step 4 of 4

Demo 04: Activity Review

See the full inbound/outbound lifecycle for each pull-and-deliver cycle.

  1. 1

    Navigate to Activity → filter by Demo 04 → Apply.

  2. 2

    Click any Completed state badge to expand and see the full inbound/outbound lifecycle — pull from source, deliver to target — for each transfer cycle.
