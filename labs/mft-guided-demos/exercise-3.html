Demo 02 — Overview

Automated Clinical Data Transfers

MFT and Boomi Integration working together — the file goes in raw and comes back renamed with the processing outcome.

What This Demo Covers

A clinical data file is uploaded via a Healthcare Upload Portal — a dedicated web application connected to Boomi MFT. The file passes into MFT, which automatically triggers a Boomi Integration process. That process validates the file and renames it with a _pass or _fail suffix based on the outcome. The renamed file appears in the Activity feed, closing the loop.

Key Capabilities

  • External upload portal feeding directly into Boomi MFT
  • MFT triggers a Boomi Integration process automatically — no manual step
  • Outcome-based file renaming (filename_pass.csv or filename_fail.csv)
  • Full round-trip visible in the Activity feed

Architecture

Healthcare Upload Portal → Boomi MFT (receives file, tracks transfer) → Boomi Integration (processes file, renames with pass/fail) → MFT Activity (renamed file visible)

Separate access required. The Healthcare Upload Portal is a standalone web application provided as part of your demo environment setup — access details will be shared separately.
Step 1 of 2

Access the Upload Portal

Open the Healthcare Upload Portal using the access details provided with your demo environment.

  1. 1

    Open the Healthcare Upload Portal using the URL and credentials provided as part of your demo environment setup.

  2. 2

    Log in and confirm you can see the file upload interface. The portal is connected directly to Boomi MFT — any file you upload will register as a new transfer immediately.

Step 2 of 2

Run the Transfer & Review Activity

Upload a file and watch the Integration round-trip complete in the Activity feed.

  1. 1

    From the Healthcare Upload Portal, upload a clinical data file. The portal is connected to Boomi MFT — the upload registers as a new transfer immediately.

  2. 2

    MFT receives the file and triggers the Boomi Integration process automatically — no manual trigger required.

  3. 3

    Switch to the Activity feed in the MFT platform. Find the processed file — it will appear renamed with either a _pass or _fail suffix based on the Integration process outcome.

The outcome-based rename shows the Integration round-trip in action — the file went in as raw clinical data and came back renamed with the processing result, all visible in the MFT Activity feed.
