Step 1 of 3

Attach Sources

Sources are systems that contribute data into the master data repository or accept updates from the master data repository. In our scenario we have two sources which contributes data to the master data repository:

Salesforce

Netsuite

We also have one source which accepts updates from the master data repository:

Marketing DB (MySQL)

We will review how these sources are created and attached to a model.

Click on the "Sources" tab then "Create a Source":

Enter the name "Marketing DB (YOUR-NAME)" where you replace YOUR-NAME with your firstname. For the Source ID enter "marketing_db_YOUR-NAME". Click "Save":

Repeat the process for Salesforce:

Repeat the process for Netsuite:

You should now see a list like this:

We will now attach the sources to our model.

Click on "Repositories" then "Training":

Click on your Customer model:

Click on the "Sources" tab then "Attach You First Source":

We will first add Salesforce as a contributing source.

Choose "Salesforce (YOUR-NAME)" from the drop down list then check "Contribute data" and click "Attach":

Click on "Attach a Source" again to attach another source:

Choose "Netsuite (YOUR-NAME)" and "Contribute data" then click "Attach":

Click "Attach a Source" again:

This time we will attach a source which will be listening for updates from the master data repository.

Choose "Marketing DB (YOUR-NAME)", check "Accept channel updates" and click "Attach":

We will now configure the Marketing DB source so that it only listens for #Prospect records. Click on the gear icon and "Configure":

Select "Apply rules to the sending of records to this source" then "#Prospect":

Scroll down and "Exclude" all the Finance Details fields. This is to ensure no finance details are sent to the Marketing DB. Then click "Save":

For the sources that are "contribute-only source" (Netsuite and Salesforce) we need to "Initial Load" them. Initial Load is a mode which allows data to be loaded into the repository without triggering synchronisation to other systems.

For this exercise we will enable and finish initial load without loading any data.

Click on the gear icon next to Netsuite and click "Enable Initial Load":

Notice that the circle has turned blue. This means it is ready for initial load. We will just finish the initial load without loading any data:

Upsert Data from Salesforce to MDH

In the left-hand corner of the browser select Integration from the Services drop down list:

Click the dropdown on your User folder and click "New Component":

Create a new Process component with name "Upsert Salesforce Account to MDH":

On the start shape choose the "Salesforce" connector, leave action as "Get" and choose the "Boomi Salesforce" connection from the "SHARED" folder as shown below:

Choose the "Get Salesforce Account by Name" operation also from the "SHARED" folder as shown below:

Click "OK":

Click on the "Parameters" link:

Click on "Import all 1?"

Click on the edit button:

Enter "GenePoint" as the static value:

Click "OK":

Drag and drop a Boomi Data Hub connector:

Select the action "UPSERT" then the connection "Boomi MDM" under the "SHARED" folder as shown below:

Create a new operation by clicking on the + button:

Name the operation "Upsert Salesforce Account to MDH" and click "Import":

Choose the "Boomi MDM" connection from the "SHARED" folder:

In the source field type "salesforce_YOUR-NAME" and click "Next".

Note — Note:

If you encounter an error during this step, which details that the ‘source has not been attached’ please visit step 7.

The Source ID generated in Step 3 is used and not the Source Name in the “Source” field of the Import Wizard.

Choose your model:

Click "Finish":

Review what’s been created then click "Save and Close":

Click "OK" on the connector page:

Drag and drop a "Map" shape:

Name the map "Salesforce Account to MDH" and click the "Choose" link on the source:

Choose the "XML" profile type and select "SF_Account_QUERY_Response" from the "SHARED" folder as shown below:

Now click on the "Choose" link on the destination section:

Choose the "XML" profile type and select "Boomi Data Hub customer<yourname> UPSERT Request" under your user folder as shown below:

Create the mappings as shown below then click "Save and Close" (you may like to use Boomi Suggest):

Note — Note: If using Boomi Suggest, ensure to deselect suggestions made on the @fields, as this will cause records to move into quarantine.

Connect the shapes as shown below, click "Save" then click "Test" to test the process:
