Boomi for SAP — Hands-on Lab V2 Preview

Learn how to integrate SAP S/4HANA with Salesforce and databases using Boomi for SAP. Work through three progressive exercises covering BAPI invocation, Table Services, and real-time Business Object Events — now with deeper explanations of the why behind every step.

~2.5 hours Intermediate 3 Exercises + Optional Step 0
V2 under review — not yet listed in the catalog. This is the updated version of the Boomi for SAP lab incorporating the field review feedback. The current published version remains live until this one is approved.

Exercises

  • 0

    Installing Boomi for SAP Optional

    A guided click-through of how the Boomi for SAP add-on is installed into an SAP system — transport upload, the SAINT wizard, ICF service setup, and launch. Your lab environment is already installed; this is for context, no hands-on required.

    ~15 min Read-through
  • 1

    Creating a Sales Order in SAP from a Salesforce Opportunity

    Read a real CRM payload, call BAPI_SALESORDER_CREATEFROMDAT2 through the Boomi for SAP connector, and learn the classic SAP mapping patterns — leading zeros, line increments of 10, sales-area defaults — with the reasoning behind each.

    ~50 min 8 steps
  • 2

    Table Services: SAP Sales Orders to a Database

    Join VBAK and VBAP into a single Table Service — complete header and line-item data in one call — then query it from an integration process and load the results into the shared workshop database.

    ~60 min 7 steps
  • 3

    Business Object Events: Real-time SAP Notifications

    Subscribe to the Sales Order CHANGED event, route it through a Topic, and receive a table-service-enriched payload in a deployed listener — real-time SAP, with the full metadata-vs-payload story explained.

    ~45 min 5 steps
