Overview

Publish & Manage as an API

Reuse the integration as a subprocess, expose it via a Web Services listener, register it with API Management, deploy and catalogue the API, attach a usage plan, subscribe via the Developer Portal, and test the live API.

What you'll cover

  1. Copy Subprocess
  2. Create Web Service Listener Process
  3. Create an API Component
  4. Deploy API
  5. Search API in API Catalog
  6. Assign Plan to API
  7. Subscribe to API on Developer Portal
  8. Test API

Step 7 of 8

Subscribe to API on Developer Portal

Access the following link for the Dev Portal:

Select ‘Sign In’.

You will then be taken to the login screen. Enter the following details for the username and password:

Username: APIUser

Password: Boomi123

Once logged in, search for your API in the API catalog using your name in the search bar.

Select your API and subscribe to your API.

Select the “TestDriveWorkshopApp” predefined application, add a message if desired for the subscription request. Select ‘Subscribe’.

Once you select ‘Subscribe’, you will see a confirmation message of the request sent.

The ‘Status’ is set as ‘Pending’. The API Producer (you in this case) will have to navigate to the Boomi APIM UI and approve the request.

Within Boomi APIM, select the ‘Approve’ tab on top. You will see the request from the API Consumer which was submitted in the previous exercise.

Once you have selected ‘Pending Approval’. You will then see the details of which the consumer has submitted.

You will then see a window where you can configure the approval for the request from the API Consumer. You can pick which plan you want imposed on this API. We only have one in this case. As you can see, you can configure the date at which the subscription will be active. You may also choose to disable the subscription automatically at a particular date.

Select ‘Approve’.

Head back to the Developer Portal, and under “Subscriptions”, you will find that your API status under the “TestDriveWorkshopApp” application is now “Enabled”. Click on your API name, and you can now find the issued API key to use to call the API.

Step 8 of 8

Test API

Test out the API using either Postman, HTTP or REST Client connector in a process, or through the “Try it out” feature on the Developer Portal. You will need to pass the API Key as a header “X-API-Key” and replace the {trainee} parameter with your name. The API URL path can be found from the Deployed API tab, from Lesson 17.

The test should return a customer JSON response. Go back to AtomSphere and click on "Manage" -> "Process Reporting":
