Boomi MFT

Modernizing the Back Office
(CRM → Partner)

Automate the distribution of invoices, purchase orders, and shipping notices from your CRM system to multiple automotive partners using Boomi's Managed File Transfer platform. Implement the fan-out pattern — routing files to BMW, Mazda, and Volkswagen automatically based on filename rules.

~90 minutes 2 exercises Intermediate
Start Lab

Exercises

1

Configure the MFT Flow

Set up the AFT portal with partner organizations (BMW, Mazda, VW), add SFTP and iPaaS connector endpoints, create the distribution flow in Flow Studio, subscribe all organizations, and wire up source and target endpoints. Capture connection credentials for the integration step.

AFT Portal Organizations Flow Studio
~30 min 4 steps
2

Build the Integration Process

In Boomi Integration, build a process that simulates CRM file generation using Branch and Message shapes, apply Set Properties steps to tag files per partner, connect an MFT Connector (Drop Off), add regex routing filters in the AFT flow, and verify that each partner receives only their files.

Boomi Integration MFT Connector Fan-Out Regex Routing
~60 min 6 steps
This lab was originally built for a live workshop.

If you're working through this outside of a workshop session, you'll need to set up your own accounts before starting. You can get access via a Boomi Integration trial or a Boomi MFT trial. Workshop participants will have accounts pre-provisioned — check your inbox for a registration email.

Prerequisites

  • Boomi Integration account — workshop attendees: your account will be created in advance and you will receive an email to complete registration. Self-guided: sign up at boomi.com/form/trial. Log in at platform.boomi.com
  • AFT portal account — workshop attendees: your account will be created in advance and you will receive an email to complete registration. Self-guided: contact your Boomi representative to request MFT trial access. Log in at staging.thruinc.com
  • Basic familiarity with the Boomi Integration canvas (shapes, connectors, process flow)
  • A personal workspace folder pre-created in Boomi Integration (set up as part of user registration)
